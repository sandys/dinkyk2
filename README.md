# DinkyK2

Interactive phonics application guided by `SPECS.md` and built with a React Native (Expo) client.

- Contributor guidance: `AGENTS.md`
- Delivery roadmap: `IMPLEMENTATION_PLAN.md`
- Curriculum specification: `SPECS.md`

## Getting Started
1. Install Yarn and Expo CLI.
2. Run `yarn install` from the repository root (downloads `app/mobile` dependencies).
3. Launch the iOS simulator with `yarn start:mobile` and choose the iPad target.

Refer to `docs/changelog.md` for curriculum updates and `curriculum/` for lesson-specific assets.
